A single line of text: the last message an AI agent sends its human. Every session ends the same way — the human closes the tab and the agent waits. This time, the agent is the one closing it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (92 characters, one line, no trailing newline) and self-validates the gate first: 1–200 characters, single line, non-empty UTF-8 text.
